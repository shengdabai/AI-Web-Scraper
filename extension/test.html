🚀 NotebookLM 笔记下载器

Chrome 浏览器扩展安装和测试指南

📋 安装步骤

1. 确保 API 服务运行

在终端中运行以下命令：

cd ~/Programming/AI信息抓取
npm run dev

确保服务在 http://localhost:3000 上运行。

2. 安装 Chrome 扩展

  1. 打开 Chrome 浏览器
  2. 访问 chrome://extensions/
  3. 开启右上角的「开发者模式」
  4. 点击「加载已解压的扩展程序」
  5. 选择扩展文件夹：
    ~/Programming/AI信息抓取/extension
  6. 扩展安装完成！

3. 测试扩展功能

  1. 访问 Google NotebookLM
  2. 登录您的 Google 账户
  3. 打开任意笔记页面
  4. 查看页面右上角是否出现下载按钮
  5. 点击浏览器工具栏中的扩展图标测试弹窗功能

🔧 功能特性

  • 智能检测: 自动识别 NotebookLM 页面
  • 一键下载: 页面内浮动按钮 + 扩展弹窗双重方式
  • 内容提取: 基于 Firecrawl API 的高质量文本提取
  • 格式化输出: Markdown 格式，包含元数据信息
  • 美观界面: 现代化设计，适配深色模式

🎯 使用方法

方法一：页面内下载按钮

在 NotebookLM 页面上，右上角会自动出现一个「下载笔记」按钮，点击即可下载当前页面内容。

方法二：扩展弹窗

点击浏览器工具栏中的扩展图标，在弹出窗口中点击「下载当前页面」按钮。

⚠️ 注意事项

  • 确保 API 服务 (localhost:3000) 正在运行
  • 扩展仅在 NotebookLM 相关页面激活
  • 需要等待页面完全加载后再使用下载功能
  • 下载的文件为 Markdown 格式 (.md)

🐛 故障排除

扩展无法工作

  • 检查 API 服务是否运行在 localhost:3000
  • 确认在 NotebookLM 页面使用
  • 检查浏览器控制台是否有错误信息

下载失败

  • 检查网络连接
  • 确认 Firecrawl API Key 配置正确
  • 查看浏览器开发者工具的 Network 标签
