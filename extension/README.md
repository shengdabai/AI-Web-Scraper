# NotebookLM 笔记下载器

一个 Chrome 浏览器扩展，用于一键下载 Google NotebookLM 笔记内容。

## 功能特性

- 🎯 **智能检测**: 自动检测 NotebookLM 页面
- 📥 **一键下载**: 点击按钮即可下载笔记内容
- 📝 **多格式支持**: 支持 Markdown 格式下载
- 🎨 **美观界面**: 现代化的用户界面设计
- ⚡ **快速响应**: 基于 Firecrawl API 的高效内容提取
- 🔒 **安全可靠**: 本地处理，保护隐私

## 安装步骤

### 1. 准备工作

确保您的 AI信息抓取 服务正在运行：

```bash
cd ~/Programming/AI信息抓取
npm run dev
```

服务应该在 `http://localhost:3000` 上运行。

### 2. 安装扩展

1. 打开 Chrome 浏览器
2. 访问 `chrome://extensions/`
3. 开启右上角的「开发者模式」
4. 点击「加载已解压的扩展程序」
5. 选择 `extension` 文件夹
6. 扩展安装完成！

### 3. 验证安装

- 在浏览器工具栏中应该能看到 NotebookLM 下载器图标
- 点击图标可以打开扩展弹窗

## 使用方法

### 方法一：页面内下载按钮

1. 访问 [Google NotebookLM](https://notebooklm.google.com)
2. 登录您的 Google 账户
3. 打开任意笔记页面
4. 等待页面完全加载
5. 点击页面右上角的「下载笔记」按钮
6. 文件将自动下载到您的下载文件夹

### 方法二：扩展弹窗下载

1. 在 NotebookLM 页面上点击浏览器工具栏中的扩展图标
2. 在弹出的窗口中查看状态信息
3. 点击「下载当前页面」按钮
4. 选择保存位置并确认下载

## 下载文件格式

下载的文件包含以下信息：

```markdown
# 笔记标题

**下载时间:** 2024-01-01 12:00:00
**原始链接:** https://notebooklm.google.com/...
**描述:** 页面描述（如果有）
**字数统计:** 1234

---

笔记内容...
```

## 故障排除

### 扩展无法工作

1. **检查 API 服务状态**
   - 确保 `npm run dev` 正在运行
   - 访问 `http://localhost:3000` 确认服务可用

2. **检查页面兼容性**
   - 确保在 NotebookLM 相关页面使用
   - 等待页面完全加载后再尝试下载

3. **检查浏览器权限**
   - 确保扩展有访问 NotebookLM 网站的权限
   - 检查是否被广告拦截器阻止

### 下载失败

1. **网络连接问题**
   - 检查网络连接
   - 确认可以访问 NotebookLM 网站

2. **API 配置问题**
   - 检查 Firecrawl API Key 配置
   - 查看浏览器控制台错误信息

3. **页面内容问题**
   - 确保页面包含可提取的内容
   - 尝试刷新页面后重新下载

### 查看详细错误信息

1. 按 F12 打开开发者工具
2. 切换到 Console 标签
3. 查看错误信息和日志
4. 根据错误信息进行相应处理

## 技术架构

### 组件说明

- **manifest.json**: 扩展配置文件
- **content.js**: 内容脚本，在页面中注入下载按钮
- **popup.html/js**: 扩展弹窗界面和逻辑
- **styles.css**: 样式文件
- **icons/**: 扩展图标文件

### API 集成

扩展通过以下 API 端点与后端服务通信：

- `POST /api/firecrawl/extract-text`: 提取页面文本内容
- `POST /api/firecrawl/scrape`: 抓取页面原始内容

### 权限说明

- `activeTab`: 访问当前活动标签页
- `downloads`: 下载文件到本地
- `host_permissions`: 访问 NotebookLM 和本地 API 服务
